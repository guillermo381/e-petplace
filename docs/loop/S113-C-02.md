## ⑤ `usarMoneda` → `useMoneda` — un nombre en español apagaba un guard

Con `verify:hooks` de E corriendo, sus **tres** violaciones eran las tres del
mismo archivo: *«React Hook "useState" is called in function "usarMoneda" that is
neither a React function component nor a custom React Hook function»*.

**La razón no es de estilo.** La regla reconoce **por prefijo** (`use…` o
mayúscula), así que un hook en español es **invisible** para ella — y lo que se
pierde no es un aviso cosmético: es **la regla entera sobre esa función**. *El
día que alguien llame a este hook después de un return —exactamente el defecto
que acaba de dejar al prestador sin abrir— el gate no lo ve.* **Un nombre que
apaga un guard cuesta más que la consistencia de idioma que compra.**

**El censo de llamadores: CERO.** Dos ocurrencias en todo el monorepo, las dos de
su propio archivo; nadie importa `usar-moneda`. ⇒ **no hubo llamadores que
actualizar y no aparecieron rojos nuevos, porque no había dónde.** Se renombró
igual —el nombre ya estaba apagando el guard— y queda dicho en el archivo: *este
hook está escrito, documentado y no lo usa nadie.*

Se renombró **también el archivo** (`git mv` a `use-moneda.ts`): *un hook que se
llama `useMoneda` en un archivo `usar-moneda.ts` deja la mitad del problema, y es
la mitad que se busca por nombre de archivo.*
